# CareerOS

CareerOS is an AI-powered career and placement platform that connects students, recruiters, and college placement cells.

## Features

- Student registration and authentication
- Student profiles
- Resume management
- Job posting and searching
- Job applications
- Recruiter dashboard
- Placement cell dashboard
- Resume analysis
- Skill gap analysis
- AI-powered job recommendations
- Interview preparation
- Notifications
- Placement analytics

## Tech Stack

### Frontend

### Backend

- Express.js
